# avantgardepartners.nl

Website van Avant-Garde Partners, via GitHub Pages (repository iworkproductions/avantgardepartners).

## Live zetten
Vervang alle bestanden in de map `avantgardepartners-nl-github (1)` door deze, en voer in Terminal uit:

    cd ~/Downloads/"avantgardepartners-nl-github (1)" && git add -A && git commit -m "update" && git push

Na een paar minuten staat de nieuwe versie online.
